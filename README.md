# Terra & Drift - Minimalist Slow Travel Journal

A static, purely HTML/CSS website designed for a minimalist travel blog. 
Hosted seamlessly on [GitHub Pages](https://pages.github.com/).

## Features
- **Zero Dependencies:** Built with pure HTML5 and custom CSS. No build tools (like npm or Webpack) required.
- **Responsive Design:** Fluid grid layout that adapts to mobile, tablet, and desktop screens.
- **Theme:** Terracotta and Sage color palette with classic Georgia typography.

## File Structure
- `index.html` - The main homepage.
- `404.html` - Custom error page for broken links.
- `style.css` - All styling, variables, and responsive media queries.

## Setup Instructions
To run this locally, simply download the files and open `index.html` in any web browser. 
No local server is required.
